# ЭИБ — демонстрационный прототип

Электронное инициативное бюджетирование: платформа полного цикла — от идеи жителя
до итогового отчёта. Пилот проектируется для города Обнинска Калужской области.

**Это демонстрационный прототип.** Проекты, суммы, фамилии и документы вымышлены и приведены
только для показа механики. Сайт не является официальным ресурсом администрации города
или иных органов власти и не принимает реальных платежей.

## Что можно посмотреть

- Витрина проектов и шесть этапов: заявка и подписи → сбор средств → отправка документов →
  выбор подрядчика → отчёт подрядчика → завершение.
- Карточка проекта со сметой, документами, карточкой закупки по 44-ФЗ, графиком работ и отчётом.
- Три роли — житель, администрация, подрядчик. Переключаются панелью «Демо · смотреть как»
  внизу слева, вход по паролю не нужен.
- Форма подачи инициативы с построчной сметой и паспорт проекта для печати.

Механика и сроки основаны на ст. 49 и 70 ФЗ № 33-ФЗ, Положении г. Обнинска № 05-22
и практике инициативного бюджетирования Калужской области.

Технически это статический сайт: HTML, CSS и JavaScript без сборки. Все действия
сохраняются только в браузере посетителя (localStorage) и никуда не передаются.
